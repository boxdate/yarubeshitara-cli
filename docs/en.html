Origin & Portability

Why "Yarubeshitara!" & The Paper Notebook Philosophy

Uninterrupted capture from the command line, backed by future-proof plain text files.

Naming Origin

"Yarubeshitara!" — "Well then, let's do this!"

"Yarubeshitara!" (やるべしたら！) is a warm, energetic phrase from the Hokkaido dialect of northern Japan meaning "Well then, let's do this!" or "Let's get to it!".

Opening a heavy browser app or wrapping arguments in quotes breaks your flow. With yarube, you simply type yarube Prepare slides for tomorrow—no subcommands or quotes required—and get right back to your work.

# No subcommand or quotes needed $ yarube Prepare slides for tomorrow # Attach an indented note to the task you just added $ yarube sub "Check display adapter in room B"
Plaintext Notebook

Portable Standard Markdown & Safe Unicode

Every daily page is stored locally as a plain Markdown file at ~/.yarube/YYYY-MM-DD.md. There is no proprietary database or lock-in—track your logs with Git, sync them via Dropbox/Nextcloud, or edit them directly in any text editor.

Status markers use only standard Unicode characters (•, O, >, ~, -, △). No Nerd Fonts or custom emojis are required, preventing garbled characters across any terminal or OS.

~/.yarube/2026-10-17.md Plain Markdown
### 10/17(Tue) #### △ Todo List O Write tests for SIT-1-1-1-001 > Spin up GitBucket on Podman - Compare Lubuntu -> Xubuntu • Build conversion tool for MCP - Convert PDF -> Markdown #### △ Reflection Switched to EndeavourOS!
Core Concept

Why Combine "TODO" and "Reflection" on a Single Page?

When your task manager and your daily journal live in separate tools, a day where plans fall apart often ends with a single lingering feeling: "Today was a failure."

yarube is purposefully designed to place "what you actually did today (facts)" and "your daily reflection (emotions & introspection)" side by side on the exact same page.

Stress Relief via Expressive Writing[1]

Pouring out impatience, fatigue, or raw thoughts with yarube reflect externalizes the mental clutter occupying your brain's working memory and resets your mind.

Metacognition by Pairing Facts with Feelings[2]

Writing your reflection while looking directly at the tasks (TODO) you actually moved forward right above it prevents excessive self-criticism and helps you regain an objective perspective (metacognition).

[1] Expressive Writing & Working Memory: Psychological studies show that writing down raw thoughts and emotions reduces intrusive rumination and frees up working memory capacity (Klein & Boals, 2001 / Pennebaker & Beall, 1986).
[2] Visualizing Small Wins (The Progress Principle): Multi-year diary studies of knowledge workers reveal that the single most important factor boosting daily motivation and emotional well-being is recognizing incremental progress ("Small Wins") (Teresa Amabile & Steven Kramer, 2011 — Harvard Business Review).
Daily Workflow

Capture, 1-Key Review & Daily Reflection

The core Bullet Journal loop—rapid logging, end-of-day migration, and reflection—streamlined into three simple steps.

STEP 1 / CAPTURE

Rapid Logging During the Day

Jot down tasks in a single line as they come up. Use yarube sub to attach indented context notes ( - ) under the most recent task.

$ yarube Benchmark API latency $ yarube sub "Check p95 response time"
STEP 2 / REVIEW & MIGRATE

1-Key End-of-Day Triage

Run yarube review to step through pending tasks. Press m (Migrate) to automatically carry a task and its subtasks over to tomorrow's file.

$ yarube review [1/2] • Benchmark API latency - Check p95 response time (o:Done / m:Migrate / c:Cancel / s:Skip) > m
STEP 3 / REFLECT & BROWSE

Write Reflections & Flip Pages

Run yarube reflect to open your favorite editor and write in "△ Reflection". Flip through past recorded days with prev or browse.

$ yarube reflect $ yarube prev $ yarube browse
Symbol Status Review Key Description
• Todo (Pending) s / Enter (Skip) Newly added task, or a task migrated from a previous day.
O Done (Completed) o Completed task. Rendered with dim + strikethrough styling so pending items stand out clearly.
> Migrated m or > Marks the task as migrated (>) today and copies it (with all subtasks) to tomorrow's Todo List as •.
~ Cancelled c or ~ Dropped or cancelled task (rendered with dim + strikethrough styling).
- Subtask / Note Follows parent Indented note attached to a parent task. Automatically migrates alongside its parent task.

Extensible Plugins

Plugin Ecosystem & Local AI Coach (yarube-coach)

Keep the core binary ultra-fast and zero-dependency while extending your workflow with process-isolated plugins.

Official Plugin #1 — yarube-coach

A Local AI Coach for "Written Meditation"[3]

Rather than pushing unsolicited advice, yarube-coach first acknowledges your feelings and asks just one focused question that directs your attention to concrete facts or a specific starting point. With nobody watching and 100% offline privacy, you can deepen your "written meditation" in a completely safe space.

Powered by Candle and Qwen3-1.7B (GGUF), it runs entirely on your CPU with zero network calls and no GPU required. Saving your journal always happens first, so your notes are safe even if a plugin is absent.

# Build & set up the yarube-coach plugin $ cargo build --release --manifest-path plugins/yarube-coach/Cargo.toml $ cp plugins/yarube-coach/target/release/yarube-coach ~/.local/bin/ $ yarube-coach setup $ yarube-coach status
On-Reflect Hook Output

One Gentle Question After You Reflect

Right after yarube reflect saves your entry, the coach streams back empathetic acknowledgment and one question styled in your active color theme, appending it to your daily Markdown log using safe standard symbols (> [Coach]).

Customize the system prompt and few-shot examples anytime in ~/.config/yarube/coach_prompt.toml, or add your own custom plugins in any language.

yarube reflect — on_reflect hook
#### △ Reflection
Switched to EndeavourOS! Everything runs super smoothly.
Still don't feel like writing tests... only uncertain specs.
> [Coach] It sounds like you're enjoying your comfortable new OS,
> yet feeling weighed down about testing due to the uncertainty.
> Question: Setting the uncertain parts aside for a moment, what is
> the smallest piece that you know for sure right now?
[3] Affect Labeling & Self-Distancing (Metacognition): Putting feelings into words and stepping back to observe concrete facts dampens amygdala reactivity and deepens objective self-insight (Lieberman et al., 2007 / Kross & Ayduk, 2011).
Commands

Command Reference

Complete CLI commands for daily logging, reviewing, searching, and configuration.

Command Action Description
yarube View Today Displays today's journal (automatically generates the daily template on first run).
yarube [t] <task text...> Add Task Appends a new task to today's "△ Todo List". Both t and quotes are optional.
yarube sub <note text...> Add Subtask Attaches an indented subtask / note ( - ) under the most recent task.
yarube review Review & Migrate Interactive 1-key review of pending tasks: o (Done), m (Migrate to tomorrow), c (Cancel), s (Skip).
yarube reflect Reflect Opens your configured editor to write or edit today's "△ Reflection" section.
yarube prev [-N] / yarube -N Previous Day Jumps back to the previous recorded day, automatically skipping unrecorded days/weekends (e.g., yarube -1, yarube -2).
yarube browse Flip Pages Interactive page-turning mode using ← / → or p / n keys.
yarube search <keyword> Full-Text Search Searches across all past daily Markdown files and highlights matching tasks and reflections.
yarube open Edit Raw File Opens today's raw Markdown file directly in your configured text editor.
yarube theme [name] Switch Theme Previews or switches the color theme (tokyo-night / monokai / nord / sepia).
yarube config editor [cmd] Set Editor Sets the editor command used for reflections (e.g., yarube config editor "code --wait", nvim, vim).
yarube config lang [en|ja] Set Language Switches CLI messages and template headings between English (en) and Japanese (ja).
Installation

Installation & Quick Setup

With zero external crate dependencies, yarube compiles in ~1 second using standard cargo.

1. Build from Source & Install Binary 
git clone https://github.com/boxdate/yarubeshitara-cli.git
cd yarubeshitara-cli
cargo build --release

# Copy the binary to a directory in your PATH
cp target/release/yarube ~/.local/bin/yarube
2. Recommended Setup (Alias & Editor) 
# Add a single-letter alias in ~/.bashrc or ~/.zshrc
alias y='yarube'

# Set language, editor, and preferred theme
yarube config lang en
yarube config editor "nvim"
yarube theme sepia
