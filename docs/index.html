ターミナルで完結する、
プレーンテキストの手帳記録。

Origin & Portability

北海道弁「やるべしたら」の由来と、手書き手帳のポータビリティ

思考を止めないコマンド入力と、どの環境でもそのまま読めるプレーンテキスト設計。

Naming Origin

「やるべしたら！」（よし、やろう！）

ツール名の Yarubeshitara（コマンド名: yarube）は、北海道弁で「よし、やろう！」「じゃあ、やろうか！」を意味する、温かく勢いのある言葉から名付けました。

作業中に思いついたタスクを書き留めるとき、ブラウザを開いたりクォート記号（""）で囲んだりする手間すら省けるよう、yarube 明日の 会議 資料作成 と打ち込むだけで即座に手帳へ追記されます。

# クォートもサブコマンドも省略してそのまま追記 $ yarube 明日の 会議 資料作成 # 直前のタスクに補足メモ（インデント）を紐づける $ yarube sub "プロジェクターの変換アダプタ確認"
Plaintext Notebook

手書き手帳のように持ち運べる標準Markdown

記録は専用データベースを使わず、すべてローカルの ~/.yarube/YYYY-MM-DD.md にプレーンなMarkdownとして保存されます。Gitでの管理やクラウド同期、普段使っているエディタでの直接閲覧・編集がそのまま行えます。

また、特殊なフォント（Nerd Fonts等）や絵文字を使わず、どの端末でも文字化けしない標準記号（•, O, >, ~, -, △）のみで手書き手帳の記号体系を表現しています。

~/.yarube/2026-10-17.md Plain Markdown
### 10/17(火) #### △ やることリスト O SIT-1-1-1-001のテスト作る > PodmanにGitbucketを立ち上げる - Lubuntu -> Xubuntuが良いか • MCP用の変換ツール作成する - PDF -> Markdown化 #### △ ふりかえり EndeavourOSにしたあき！
Daily Workflow

1日の記録・棚卸し・ふりかえり

紙のバレットジャーナルの「タスク書き出し → 完了・翌日移行の仕分け → ふりかえり」をシンプルな3ステップで回せます。

STEP 1 / 日中の記録

タスクと補足メモを書く

思いついた瞬間にワンライナーで記録。直前のタスクに対するメモは yarube sub でインデント（ - ）として紐づきます。

$ yarube APIのレスポンス計測 $ yarube sub "p95レイテンシを確認"
STEP 2 / 夕方の棚卸し

1キーで完了・翌日へ引き継ぎ

yarube review で未完了タスクを1件ずつ確認。m（移行）を押したタスクは、補足メモごと翌日の手帳へ自動転記されます。

$ yarube review [1/2] • APIのレスポンス計測 - p95レイテンシを確認 (o:完了 / m:翌日移行 / c:取消 / s:スキップ) > m
STEP 3 / ふりかえり・見返し

エディタで所感を書き、過去をめくる

yarube reflect で愛用エディタを起動し「△ ふりかえり」を記述。過去の記録は prev や browse でパラパラ見返せます。

$ yarube reflect $ yarube prev $ yarube browse
記号 状態 review キー操作 説明
• 未完了 (Todo) s / Enter (スキップ) 新しく追加したタスク、および前日から引き継がれたタスク。
O 完了 (Done) o 完了したタスク。表示時は薄字＋取り消し線になり、未完了タスクがひと目で分かります。
> 翌日へ移行 (Migrated) m または > 翌日の「△ やることリスト」へ自動転記されたタスク。サブ項目も一緒に引き継がれます。
~ 取消 (Cancelled) c または ~ 実行を取りやめたタスク（表示時は薄字＋取り消し線）。
- サブ項目 (Subtask) 親タスクに連動 親タスクに紐づく補足メモ。親タスクを翌日へ移行すると一緒に引き継がれます。

Commands

コマンド一覧

日常の記録から過去日の検索、エディタ設定までのコマンドリファレンス。

コマンド 用途 説明
yarube 表示 今日の手帳を表示します（当日初回はテンプレートを自動作成）。
yarube [t] <タスク内容...> タスク追加 今日の「△ やることリスト」へタスクを追記します。t やクォートの省略に対応しています。
yarube sub <補足メモ...> サブ項目追加 直前のタスクに対して補足メモ（ - ）を紐づけます。
yarube review 棚卸し・移行 未完了タスクを1件ずつ確認し、o（完了）/ m（翌日移行）/ c（取消）/ s（スキップ）で整理します。
yarube reflect ふりかえり エディタを起動して「△ ふりかえり」を記入します。
yarube prev [-N] / yarube -N 過去日表示 休日などの未記録日を飛ばして、直前に書いた手帳を表示します（例: yarube -1, yarube -2）。
yarube browse ページめくり 記録のある日付を矢印キー（← / →）や p / n キーで前後にめくって閲覧します。
yarube search <キーワード> 全文検索 過去すべての手帳から一致するタスクやふりかえり行をハイライト抽出します。
yarube open ファイル編集 今日の手帳Markdownファイル全体を設定エディタで直接開きます。
yarube theme [name] テーマ変更 カラーテーマの確認・切り替え（tokyo-night / monokai / nord / sepia）。
yarube config editor [cmd] エディタ設定 使用するエディタを設定します（例: yarube config editor "code --wait", nvim, vim）。
yarube config lang [ja|en] 言語切替 表示言語とテンプレート見出しを日本語（ja）または英語（en）に切り替えます。
Installation

インストールと初期設定

Rustツールチェーン（cargo）があれば、外部パッケージのダウンロードなしで約1秒でビルドできます。

1. ビルドとバイナリの配置 
git clone https://github.com/boxdate/yarubeshitara-cli.git
cd yarubeshitara-cli
cargo build --release

# PATHの通ったディレクトリへ配置
cp target/release/yarube ~/.local/bin/yarube
2. おすすめの初期設定（エイリアス・エディタ） 
# ~/.bashrc や ~/.zshrc に1文字エイリアスを設定
alias y='yarube'

# ふりかえりで使うエディタとお好みのテーマを設定
yarube config editor "nvim"
yarube theme sepia
